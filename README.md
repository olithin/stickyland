# Stickyland

Local desktop notes app (Notion-style).

---

## Install

Download the installer from **[Releases](../../releases)** — no Git clone, no scripts.

| OS | File |
|----|------|
| **Windows** | **`.msi`** |
| **macOS Apple Silicon** (M1/M2/M3/M4) | **`*-mac-arm64.dmg`** |
| **macOS Intel** | **`*-mac-x64.dmg`** |

macOS 11 (Big Sur) or later. Apple Silicon and Intel need different installers.

Full guide: **[INSTALL.md](INSTALL.md)**

---

## Features

| Feature | Description |
|---------|-------------|
| Notes | Create, edit, delete |
| Suites | Group notes by topic |
| Nested notes | Drag-and-drop reorder / nest |
| Screenshots | Paste from clipboard, fullscreen view |
| Search | Title and content |
| Auto-save | Saves while you type |
| Local database | SQLite file on first launch |

| Action | How |
|--------|-----|
| Paste screenshot | `Ctrl+V` (Windows) / `Cmd+V` (Mac) |
| Drag note | Hold **⠿** |
